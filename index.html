研策台使用说明

          
不用懂技术，按下面的步骤就可以开始使用。

        

        
      


      

        
第一次使用，只需要做 3 件事

        
    
          
  1. 添加股票在“添加股票”面板中输入 6 位股票代码，例如 600519，然后点击“添加/更新”。
    2. 
          
  2. 查看分析点击“个股”，选择股票后查看行情、趋势、财务、风险和事件信息。
    3. 
          
  3. 需要 AI 时再配置点击右上角“大模型配置”，填入自己的模型和 API Key；不配置也能正常使用规则看板。
    4. 
        

      


      

        

          
看板、简报、个股分别看什么？

          
    
            
  • 看板：快速查看所有股票的涨跌、趋势、风险和提醒。
    • 
            
  • 简报：汇总当天值得关注的变化，可以复制或下载。
    • 
            
  • 个股：查看一只股票的详细数据，并生成对应观察风格的 AI 报告。
    • 
          

        

        

          
观察风格有什么用？

          
观察风格决定 AI 分析时关注什么。短线更重视量价和趋势，长期更重视财务和经营，风险观察会优先检查回撤和风险事件。

          
需要修改时，在股票列表中点击“编辑”。

        

        

          
大模型怎么选？

          
    
            
  • 自动：推荐使用，先尝试浏览器直连，不行再使用网站代理。
    • 
            
  • 浏览器直连：数据直接发给模型服务商，但部分模型可能不支持。
    • 
            
  • 网站代理：兼容性较好，请求经过网站但不会被研策台保存。
    • 
          

        

        

          
我的数据保存在哪里？

          
自选股、持仓设置、观察理由和 AI 报告都保存在当前浏览器，不会保存到研策台云端数据库。

          
更换浏览器、清理网站数据或更换电脑前，请先点击“导出本地备份”。

        

        

          
如何备份和恢复？

          
    
            
  • 点击“导出本地备份”，下载 JSON 备份文件。
    • 
            
  • 在另一台电脑点击“导入本地备份”，选择这个文件。
    • 
            
  • 为了安全，备份文件不包含 API Key，恢复后需要重新填写。
    • 
          

        

        

          
遇到问题怎么办？

          
    
            
  • 已部署的站点直接打开网页即可；在自己的电脑上使用，需要先双击 StartAgent.bat 启动本地服务。
    • 
            
  • AI 无法使用：重新打开“大模型配置”，检查页面给出的验证结果。
    • 
            
  • 行情没更新：点击“刷新真实数据”。
    • 
          

        

      


      

        请注意：研策台是研究和复盘工具，不会自动下单，也不构成投资建议。AI 可能出错，重要信息请以交易所公告和正式财务报告为准。
